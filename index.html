Stacks for Mac

A new way to create pages in RapidWeaver. Stacks combines drag-and-drop simplicity with the power of fluid layouts, enabling responsive designs that adapt seamlessly to any theme.

Fluid Layout

Build pages that flow effortlessly to your theme's dimensions, even with variable widths. Create flowing columns, flexible rows, and image tiles that scale perfectly across devices.

Nesting Objects

Stack columns within columns, rows within columns, or group elements inside boxes. Unlock near-limitless layout possibilities with intuitive nesting.

Download More Stacks

Access hundreds of professionally designed stacks—free and low-cost. Instantly elevate your site with ready-to-use, high-quality content.

Live Image Editing

Resize, rotate, and style images directly in the layout using an intuitive HUD. Changes appear in real-time for precise control.

Pros Welcome

Generate clean, valid HTML with relative positioning from a simple two-div structure. Prototype complex layouts and integrate custom code effortlessly.

How It Works

Step 1: Drag and Drop

Add stacks to your RapidWeaver page with simple drag-and-drop. Start with rows, columns, or pre-built elements from the library.

Step 2: Nest and Customize

Nest objects freely—columns in columns, images in boxes. Adjust spacing, alignment, and responsiveness using the HUD.

Step 3: Edit Live

Style images and text in real-time. Preview fluid layouts across theme widths without leaving the editor.

Step 4: Publish

Export clean HTML ready for any RapidWeaver theme. Download additional stacks or build your own via the API.
